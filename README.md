# PIXELARC 웹사이트 — 사용 설명서

카페24 호스팅은 물론, GitHub + Netlify 조합으로도 그대로 사용할 수 있는 순수 HTML/CSS/JS 사이트입니다.
별도 서버 프로그램(PHP, Node 등) 설치 없이, 파일을 그대로 올리거나 깃허브에 푸시하기만 하면 동작합니다.

## 폴더 구조
```
pixelarc/
├─ index.html                메인 페이지
├─ about.html                어바웃 페이지
├─ service.html               서비스 페이지
├─ portfolio.html             포트폴리오 목록 페이지
├─ portfolio-detail.html      포트폴리오 상세 페이지 (모든 작업물 공용, ?id=로 구분)
├─ contact.html               문의 페이지
├─ css/
│  └─ style.css               전체 디자인 (색상, 레이아웃, 모바일 반응형 전부 여기)
├─ js/
│  ├─ common.js               헤더/푸터/모바일메뉴 (모든 페이지 공통)
│  ├─ portfolio-data.js       ⭐포트폴리오 추가/수정은 이 파일만⭐
│  ├─ portfolio.js            포트폴리오 화면을 그려주는 로직 (평소엔 안 건드려도 됨)
│  └─ contact.js              문의 폼 검증 + Netlify Forms 전송
└─ images/                    이미지 폴더 (직접 사진 넣는 곳)
   └─ portfolio/
```

## 1. 카페24에 올리는 방법
1. 카페24 호스팅 관리자 페이지 → FTP 정보 확인 (호스트, 계정, 비밀번호)
2. FileZilla 같은 FTP 프로그램으로 접속
3. `pixelarc` 폴더 안의 내용물(폴더 포함)을 전부 웹 루트 폴더(보통 `html` 또는 `www`)에 업로드
4. `www.내도메인.com` 접속해서 확인

## 2. 사진 / 로고 / 영상 넣는 방법
모든 이미지 자리는 회색 사선 무늬 박스(`이미지 자리`라고 적힌 부분)로 표시되어 있습니다.

**방법 A. 이미지로 교체하기 (추천)**
해당 html 파일을 열어서 아래처럼 생긴 부분을 찾습니다.
```html
<div class="img-placeholder">히어로 배경 이미지</div>
```
이 한 줄을 아래처럼 `<img>` 태그로 바꿔주세요.
```html
<img src="images/hero.jpg" alt="히어로 이미지" style="width:100%;height:100%;object-fit:cover;">
```
`images` 폴더에 실제 사진 파일을 넣고, `src="images/파일명"` 부분만 그 파일명으로 맞추면 됩니다.

**로고 이미지 넣는 방법**
- `images` 폴더에 픽셀아크 로고 파일을 넣고, 파일명을 `logo.png` 로 맞춰주세요. (경로: `images/logo.png`)
- 헤더는 자동으로 `images/logo.png`를 불러오도록 되어 있어서, 파일만 넣으면 바로 상단 왼쪽 로고에 적용됩니다.
- 로고 높이는 기본 28px로 맞춰져 있어요. 크기를 바꾸고 싶으면 `css/style.css`에서 `.logo-img{ height:28px; }` 값을 수정하세요.
- 로고 파일을 아직 안 넣은 상태라면 "LOGO" 라고 적힌 회색 박스가 대신 보입니다.

**그 외 아이콘도 동일합니다.** 각 페이지의 아이콘(💡▶📱📅 등 이모지로 임시 표시된 부분)을 원하는 이미지로 교체하시면 됩니다.

## 3. 포트폴리오 추가/수정하는 방법 ⭐가장 중요⭐
`js/portfolio-data.js` 파일 하나만 열면 됩니다. 이 파일 안에는 이렇게 생긴 덩어리가 여러 개 있습니다.
```js
{
  id: 'daegu-tiktaka',
  title: '대구보건대학교 티키타카',
  ...
},
```
**새 작업물을 추가**하려면:
1. 위 덩어리 하나를 통째로 복사
2. 배열 안 아무 곳에나 붙여넣기 (쉼표 `,` 로 구분되어 있으면 됩니다)
3. `id`를 겹치지 않는 새로운 영문 값으로 변경
4. `title`, `date`, `category`, `layout`, `thumbnail`, `videoEmbed` 등 나머지 값을 새 작업물에 맞게 수정

이렇게 하면 메인페이지 미리보기, 포트폴리오 목록, 필터, 상세페이지, 추천영상까지 **전부 자동으로 반영**됩니다. 파일 안에 각 항목이 무엇을 의미하는지 한글 주석으로 자세히 설명되어 있으니 참고하세요.

## 3-1. 메인 페이지 포트폴리오 미리보기(4개)만 따로 관리하기
메인 페이지의 "주요 작업 포트폴리오" 영역은 `js/home-portfolio-data.js` 파일에서 **별도로** 관리합니다.
(포트폴리오 목록 페이지와 다른 썸네일을 써도 되고, 원하는 포트폴리오로 자유롭게 링크를 걸 수 있습니다.)

```js
{
  thumbnail: 'images/home/main1.jpg',   // 메인 전용 썸네일 (비율 달라도 OK)
  categoryLabel: '유튜브 콘텐츠',
  title: '대구보건대학교 티키타카',
  link: 'portfolio-detail.html?id=daegu-tiktaka'  // 클릭 시 이동할 포트폴리오
}
```
배열의 순서 = 배치 순서입니다. **1번째 = 왼쪽 큰 이미지 / 2번째 = 오른쪽 위 가로형 이미지 / 3·4번째 = 오른쪽 아래 정사각형 이미지 2개**로 자동 배치됩니다.

**유튜브/인스타그램 영상 넣는 법**
- 유튜브 영상 페이지에서 [공유] → [퍼가기(embed)] 클릭 → 나오는 코드 전체 복사
- `videoEmbed: ''` 안에 그대로 붙여넣기
  ```js
  videoEmbed: '<iframe width="560" height="315" src="https://www.youtube.com/embed/영상ID" title="YouTube video" frameborder="0" allowfullscreen></iframe>',
  ```

## 4. 문의(콘택트) 폼 받는 방법 — Netlify Forms
이 사이트가 Netlify에 배포되어 있다면 **별도 설정 없이 자동으로** 문의 내용이 수집됩니다.
(`contact.html`의 폼에 이미 `data-netlify="true"` 속성이 들어가 있어서, Netlify가 배포 시 자동으로 이 폼을 인식합니다.)

**문의 내용 확인하는 방법**
1. Netlify 대시보드 접속 → 해당 사이트 클릭
2. 상단 메뉴 **Forms** 클릭 → `contact` 폼 선택
3. 제출된 문의 목록과 첨부파일을 바로 확인 가능

**이메일로 알림 받는 방법 (추천)**
Netlify를 자주 안 들어가도 문의를 놓치지 않도록, 제출될 때마다 이메일 알림을 받을 수 있습니다.
1. Netlify 대시보드 → 해당 사이트 → **Forms** → **Notifications**
2. **Add notification** → **Email notification** 선택
3. 알림 받을 이메일 주소 입력 후 저장

이제 문의가 등록될 때마다 지정한 이메일로 알림 메일이 자동으로 옵니다.
(Slack으로 받고 싶다면 같은 화면에서 Slack 연동도 선택할 수 있습니다.)

**참고**
- Netlify 무료 요금제는 월 100건까지 폼 제출이 무료입니다.
- 첨부파일은 최대 50MB까지 허용되어 있지만, 실제 안정적으로 전송되는 용량은 약 10~15MB 이내를 권장드립니다.
- 스팸 방지를 위해 폼에 보이지 않는 허니팟 필드가 이미 적용되어 있습니다 (`contact.html`의 `bot-field` 부분, 건드리지 않으셔도 됩니다).

## 5. 디자인(색상/폰트) 바꾸는 방법
`css/style.css` 파일 맨 위 `:root { ... }` 부분의 색상 값만 바꾸면 사이트 전체 색상이 한 번에 바뀝니다.
```css
--c-accent: #4C6FFF;   /* 포인트 색상(강조 파란색) */
--c-black:  #0b0d11;   /* 진한 배경색 */
```

## 6. 모바일 화면
900px 이하 화면(태블릿/모바일)에서는 상단 메뉴가 햄버거 버튼으로 바뀌고, 모든 그리드/섹션이 자동으로 1~2열로 재배치됩니다. 별도 설정 없이 그대로 사용하시면 됩니다.
